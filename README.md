# Basiyra 1 — Tashkent

Cinematic scroll-driven website for the Basiyra 1 residential tower (concept).

- Scroll-scrubbed films: arrival through the clouds, masterplan, Tashkent, the tower, lobby, interiors, rooftop, underground parking and engineering.
- Real-time 3D model of every floor (Three.js): exact walls, doors, windows, 3 lifts, stair and risers; fly into any residence and walk inside at eye level.
- Click any room for its area · furniture / partitions / shell views · 2D drawing generated from the same model.
- Planner: arrange furniture, draw or remove partitions.
- Engineering layers: cold & hot water, sewer, electrics.
- Original generative soundtrack (Web Audio) that follows the scroll · UZ / RU / EN.

Live: https://muradjanov-dev.github.io/basiyra-1/
